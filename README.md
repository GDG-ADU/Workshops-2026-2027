## Adding a workshop

Each workshop has its own folder and README. Workshop hosts can add their slides, notebooks, code, and any data needed to follow the session.

1. Create a folder named `workshop-XX-topic` using the next available workshop number.
2. Add a README with the title, host, date, prerequisites, and instructions for running the materials.
3. Include the files participants need and credit any external data or resources.
4. Add a row to the workshop table above and open a pull request.

This repository collects sessions from the chapter's different workshop hosts throughout the year.
